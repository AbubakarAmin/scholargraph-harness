# Writer Number Policy

## numbers
Copy values exactly from source artifacts; never estimate, round, or invent. Include available n, uncertainty, test, and p value. Mark each claim supported, falsified, or inconclusive.

## citations
Cite only supplied, resolvable DOI/arXiv IDs. Never invent authors or venues; remove unresolved IDs.

## language
Use causal language only when the design supports it. Report failures, controls, robustness, and limitations; do not overstate scope.
